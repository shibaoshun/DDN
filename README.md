# DDN

Repository for the paper:

**A Pretrained Deep Dictionary Network for Multi-Organ Low-Dose CT Denoising**

DDN combines multilayer sparse coding, dynamic dictionaries, adaptive
thresholds, and large-scale multi-organ CT pre-training for LDCT denoising.

## Release Status

The implementation code and pretrained model weights are being prepared
and will be released in this repository upon acceptance.
